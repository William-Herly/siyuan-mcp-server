## 发现与修正

1. **恢复档案不可用。** 真实恢复演练发现 export sy 的 ZIP 内是 Markdown，只是扩展名为 .sy，无法由 import sy 恢复。原先仅检查文件头不可靠。现在检查原生 NodeDocument JSON、目标 ID、目录布局和解压大小；失败返回 BACKUP_FAILED、not-started、retryable=false，首次正文修改不会执行。未以 HTTP、直接文件操作或弱化备份替代。
2. **列表和表格验证误报。** 改为比较 Markdown 语法结构，兼容生成属性、列表松紧和表格空格，同时测试代码字面量、链接、硬换行、嵌套和表格对齐差异。仍只执行一次规定范围的服务端读回。
3. **测试替身不充分。** 原测试仅生成 ZIP 文件头，现改为原生结构夹具，另测伪原生 Markdown、损坏 ZIP、路径和目标身份错误。真实测试区分通过与阻断。
